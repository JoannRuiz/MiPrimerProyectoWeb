¿Qué es la Ingeniería Web?

La Ingeniería Web es la disciplina que aplica principios de ingeniería de software al diseño, construcción y mantenimiento de aplicaciones web. Una aplicación web funciona bajo el modelo cliente-servidor: el navegador (cliente) solicita recursos y el servidor responde con páginas HTML, hojas de estilo, scripts y datos.

Herramientas del entorno de desarrollo

  • Editor de código: Visual Studio Code, para escribir y organizar el proyecto.
  • Navegador: Google Chrome o Firefox, para visualizar y probar la página.
  • Servidor local: extensión Live Server, que recarga la página al guardar.
  • Herramientas de desarrollador: DevTools (tecla F12), para inspeccionar HTML, CSS y errores.
